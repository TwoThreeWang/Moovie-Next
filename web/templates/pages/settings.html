播放源

订阅地址指向一个由你自己维护的 JSON 文件，里面列出你的播放源。查询和播放都由浏览器直接连接，本站的服务器不会访问这些地址。

在其他设备上登录同一个账号，播放源会自动同步过去。同步时订阅地址先在你的浏览器里用登录密码加密，服务器只保存密文，解不开。

点击保存后，收到账号保存确认才会生效。需要浏览器支持加密；无法加密或上传失败时会显示原因并保留原配置。

    订阅文件的格式 
    {
  "version": 1,
  "sources": [
    {
      "key": "a",
      "name": "我的源 A",
      "api": "https://example.com/api.php/provide/vod/"
    }
  ]
}

    每个源需要一个不变的 key。目前支持苹果 CMS 格式的 JSON 和 XML 接口。

    也可以直接填 TVBox 配置地址：只导入其中苹果 CMS 类型（type 0 / 1）的站点；需要 TVBox 爬虫的站点、解析接口和直播源网页里用不了，会自动跳过。加密的配置和多仓配置暂不支持。
