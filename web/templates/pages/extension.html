浏览器插件

影牛豆瓣助手装在电脑上的 Chrome 或 Edge 里。它用你自己浏览器里的豆瓣登录状态同步想看和看过，在豆瓣页面上直接显示你在影牛的记录，还能把豆列导入成片单、把豆瓣标记备份到电脑上。

装了有什么用

  • 同步更及时在你自己的浏览器里读豆瓣，不用排服务器的队，也不受服务器那边豆瓣限流的影响。不装插件时，同步可能不及时，甚至失败
  • 不公开的标记也能同步用你的登录状态读，豆瓣标记没公开也行，不用填豆瓣 ID
  • 豆瓣页上的影牛卡片豆瓣电影页右侧显示你在影牛的标记、看到第几集、收录它的片单、相似推荐，一键去影牛播放
  • 海报角标豆瓣的榜单、搜索、豆列、别人的收藏页上，标出你在影牛想看、看过的
  • 豆列导入片单在豆列页面点一下，导入成影牛的私密片单，检查后再决定要不要投稿
  • 备份豆瓣标记把看过、在看、想看，连同评分、短评、标签和时间，下载成 JSON 或 Excel 能打开的 CSV
  • 追剧提醒想看的、看过几集的剧有新一集时，电脑上弹出提醒
  • 写回豆瓣（实验）可选：在影牛上标记的想看、看过同步写到豆瓣，默认关闭
Chrome Edge 其他浏览器

在 Chrome 里安装

  1. 下载并解压

    点上面的「下载插件压缩包」，解压后得到一个 {{.Folder}} 文件夹。把它放到一个不会被误删的地方，比如「文档」里：插件运行时一直要用这个文件夹，以后更新也解压到这里。

  2. 打开扩展程序页

    在地址栏输入 chrome://extensions 回车；或者点右上角 ⋮ →「扩展程序」→「管理扩展程序」。

  3. 打开「开发者模式」

    开关在页面右上角。

  4. 点「加载已解压的扩展程序」

    选刚才解压出来的 {{.Folder}} 文件夹。要选里面直接有 manifest.json 的那一层，不要选外面再套的一层。

  5. 把插件固定到工具栏

    点地址栏右边的拼图图标，把「影牛 Moovie 豆瓣助手」旁边的图钉点亮，以后点小牛图标就能看同步状态。

  6. 连接影牛账号

    装好后会自动打开连接页，点「允许连接」。没打开的话，点插件图标 →「连接影牛账号」。连接后插件马上开始同步豆瓣标记。

在 Edge 里安装

  1. 下载并解压

    点上面的「下载插件压缩包」，解压后得到 {{.Folder}} 文件夹，放到不会被误删的地方。

  2. 打开扩展页

    在地址栏输入 edge://extensions 回车。

  3. 打开「开发人员模式」

    开关在页面左侧栏的下方（窗口窄时在右上角的菜单里）。

  4. 点「加载解压缩的扩展」

    选 {{.Folder}} 文件夹（里面直接有 manifest.json 的那一层）。

  5. 显示在工具栏并连接账号

    点地址栏右边的拼图图标，打开「在工具栏中显示」。装好后会自动打开连接页，点「允许连接」。

其他浏览器

360 极速浏览器、QQ 浏览器、搜狗浏览器等用 Chromium 内核的浏览器，一般也在扩展管理页里有「开发者模式」和「加载已解压的扩展程序」，步骤和 Chrome 一样。我们没有逐个测试过，内核版本要在 116 以上。

Firefox、Safari 和所有手机浏览器暂时不支持。

怎么更新

插件每天检查一次新版本。有新版本时，工具栏上的小牛图标会出现「新」字，并弹出一条提醒；插件的弹窗和设置页里也能看到。

  1. 下载新的压缩包

    在这个页面点「下载插件压缩包」，下载的就是最新版本。

  2. 解压，覆盖原来的文件夹

    解压到原来放 {{.Folder}} 的位置，提示有同名文件时选「替换」。

  3. 重新加载插件

    打开 chrome://extensions（Edge 是 edge://extensions），在影牛插件上点刷新图标。版本号变成新的就好了，设置和账号连接都还在。已经打开的豆瓣页面要刷新一下。

不要先「移除」再重新加载：移除会清掉插件的设置和连接，之后要重新连接一次账号。

插件会读取和发送什么

  • 同步时，插件用你浏览器里的豆瓣登录状态读你自己的标记列表，把豆瓣返回的内容原样交给影牛导入。插件不读取、也不上传你的豆瓣密码和 Cookie。
  • 在豆瓣页面上，插件把页面上作品的豆瓣 ID 发给影牛，查你的标记和进度。影牛上这部作品的资料缺了或者过期了，插件会把页面上片名、海报、信息栏、简介这几块交给影牛，不含你的豆瓣账号信息。
  • 帮影牛补全资料时，插件向豆瓣请求作品详情不带 Cookie，不算在你的豆瓣账号头上。请求很慢（7 秒以上一次，每天最多 300 部），豆瓣一拒绝就停。补得越多，你主页上的称号越高（拾片人、场记、资料员、档案官、片库守护者、影史编修），主页公开的话还会上贡献榜。
  • 插件只在 douban.com 和本站上运行，不记录你看了哪些网页。设置和连接凭证只存在这台电脑上。
  • 插件拿到的是一个单独的凭证，不是你的影牛密码。改密码会让它失效；也可以随时在插件设置里，或者本站「设置 → 浏览器插件」断开。

常见问题

  1. 为什么不在应用商店里？

    插件要在你的浏览器里访问豆瓣，暂时没有上架应用商店，所以用开发者模式加载。Chrome 有时会提示「停用开发者模式扩展程序」，点「保留」或者关掉提示就行。

  2. 豆瓣让我输验证码了。

    插件一碰到豆瓣拒绝就会停下来（补全资料停 6 小时，同步停半小时），不会去碰验证码，你在豆瓣网页上照常输入就行。经常这样的话，可以在插件设置里关掉「帮影牛补全资料」。

  3. 同步完少了几部？

    只同步电影和剧集；豆瓣上已经删掉或者不公开的条目收不进来。影牛上原有的标记不会被覆盖，只有「想看」会升级成「看过」。

  4. 插件装好了，弹窗里说没登录豆瓣。

    插件用的是这个浏览器里的豆瓣登录状态。在同一个浏览器里打开 douban.com 登录一次，再点「立即同步」。

  5. 怎么卸载？

    在扩展程序页移除插件，再到本站「设置 → 浏览器插件」点「断开全部插件」。已经同步过来的标记会保留。
