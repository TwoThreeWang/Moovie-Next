添加到桌面

把 {{.Site}} 添加到手机桌面后，点图标就能打开，全屏显示、没有地址栏，用起来和 App 一样。不用下载安装包，也不占多少空间。

你已经在用桌面版了

从桌面图标打开时就是全屏模式。登录账号后，播放源和观看记录会自动同步过来。

iPhone / iPad 安卓手机 电脑 在微信、QQ 里

iPhone / iPad

你现在用的不是 Safari。iOS 16.4 以上的 Chrome、Edge 也能添加（步骤一样，分享按钮在地址栏右侧）；版本较老的话，请复制网址到 Safari 里打开。

  1. 用 Safari 打开本站

    在微信、QQ 里打开的，先点右上角 ···，选「在 Safari 中打开」。

  2. 点分享按钮

    iPhone 在屏幕底部中间 分享；iPad 在右上角。新版 iOS 地址栏收起时，先点一下底部的地址栏让工具栏出来。

  3. 选「添加到主屏幕」

    在弹出的菜单里往下滑就能看到。没有的话，滑到最下面点「编辑操作」，把它加进来。

  4. 点右上角「添加」

    桌面上会出现小牛图标，以后从这里打开。

  5. 第一次打开：登录一次

    苹果让桌面版和 Safari 分开保存数据，所以桌面版要再登录一次。登录后播放源和观看记录会自动同步过来，不用别的操作。

安卓手机

已经添加好了，可以回到桌面找小牛图标打开。

  1. 用 Chrome 或手机自带的浏览器打开本站

    在微信、QQ 里打开的，先点右上角 ···，选「在浏览器打开」。

  2. 打开浏览器菜单

    Chrome 点右上角 ⋮；华为、小米、OPPO、vivo 的自带浏览器点底部的 ☰ 或「菜单」。

  3. 选「添加到主屏幕」

    不同浏览器叫法不同，可能是「安装应用」「添加到桌面」「添加快捷方式」。

  4. 确认添加

    如果提示没有权限、或者桌面上没出现图标：打开手机的「设置 → 应用 → 浏览器 → 权限」，允许「桌面快捷方式」，再试一次。

安卓上桌面版和浏览器共用登录状态和播放源，添加后直接就能用。

电脑

  1. Chrome、Edge

    地址栏右侧有一个安装图标，点它；或者打开菜单，选「投放、保存和分享 → 将网页作为应用安装」（Edge 是「应用 → 将此站点作为应用安装」）。

  2. Mac 上的 Safari

    macOS 14 以上：菜单栏「文件 → 添加到程序坞」。

在微信、QQ、微博里打开的

这些 App 内置的浏览器不能把网页添加到桌面，也可能限制视频播放。

  1. 点右上角 ···

    有的 App 是右上角的分享图标。

  2. 选「在浏览器打开」

    iPhone 上显示为「在 Safari 中打开」。

  3. 按上面对应手机的步骤添加

    打开后回到这一页，会自动显示对应的步骤。

添加后有什么不同

  • 全屏没有地址栏和工具栏，画面更大
  • 一键打开在桌面上，和其他 App 放在一起
  • 启动更快图标、样式和脚本存在手机上，不用每次重新下载
  • 断网有提示没网时显示提示页，不会白屏
