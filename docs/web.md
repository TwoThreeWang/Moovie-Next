# 公开页面、SEO 与安装

## 不登录能看什么

- 能看：首页介绍、发现、搜索作品、作品详情（含相似推荐、短评）、影评、片单、热搜榜、公开的个人主页和月度报告、说明页，以及在线 M3U8 播放器。
- 要登录：播放作品、查源、想看 / 看过 / 评分、发短评和回复、通知、设置、反馈、后台、为你推荐。
- 搜索引擎：每页有独立的标题、描述、关键词、canonical、Open Graph / Twitter Card 和 JSON-LD；`/sitemap.xml` 是站点地图索引，涵盖公开页面、资料完整的作品和审核通过的公开片单，`/robots.txt` 排除接口、播放和个人页面。

## 搜索引擎优化

不登录能看的页面都带标题、描述、关键词、canonical、Open Graph / Twitter Card 和结构化数据；登录后才有的页面（个人中心、设置、通知、后台、播放、登录注册等）和错误页一律 `noindex`，只输出标题和默认描述。

- **统一生成**：`<head>` 由 `internal/app/head.go` 的 `prepareHead` 在整页渲染前统一生成，模板只输出。页面只提供自己的 `SEO`（标题不带站点名、描述、关键词），站点名后缀、默认描述、长度限制都在这一处：
  - 标题是"页面标题 - 站点名"（站点名来自 `SITE_NAME`，默认 `Moovie 影牛`）；首页是"站点名 - 发现你的下一部电影"。分享标签（`og:title`、`twitter:title`）不带站点名，站点名放在 `og:site_name`。
  - 描述最多 120 字（中文搜索结果大约显示这么多），没有描述的页面用站点默认描述。
  - 关键词是页面自己的关键词，太少时补上通用关键词，最后加站点名，最多 10 个。
  - 页面没有自己的图片时，分享图用站点图标（Twitter 用小卡片）；有海报或封面时用大图卡片。
- **首页、发现、搜索、影院、热搜榜、片单广场、说明页、更新记录、添加到桌面、M3U8 播放器**都有按搜索习惯写的标题（如"热门电影推荐 - 按类型、年代和评分筛选"、"影视热搜榜 - 大家都在搜的电影和剧集"）和各自的描述。分页在标题和描述里加"第 N 页"。

- **作品详情**：标题是"片名（年份） - 类型简介、演员表、短评"；描述由导演、主演、类型、豆瓣评分和简介拼成；关键词是片名、原名、"片名 年份"、类型、题材、导演和主演；结构化数据包含面包屑。电影使用 `Movie`，单季页面使用 `TVSeason`，通过 `partOfSeries` 关联整剧及其 IMDb、TMDB 对应条目。
- **内容直接写在页面里**：没登录的访客（包括爬虫）打开详情页时，短评和相似推荐由服务器直接输出，不是滚动到附近才加载。很多爬虫（比如百度）不执行脚本，这样它们读得到内容，也能顺着链接发现其他作品。登录用户仍然是懒加载。
- **不收录但跟踪链接**（`noindex,follow`）：带关键词的搜索结果、"相似作品"列表、资料还没补全的作品、个人主页和观影报告。
- **公开片单**：标题是"片单名 - 片单"；描述用作者写的简介，没写或不到 30 字时补上作者、作品数和前几部作品；关键词含片单名和前几部作品。
- **片单广场和公开片单**使用 `CollectionPage`、`ItemList` 和面包屑。广场分页使用各自的 canonical。热门排序、仅链接可见的片单和空片单用 `noindex`。**首页**使用 `WebSite`（站点名称）。
- `robots.txt` 指向 `/sitemap.xml`。索引列出公开页面、作品和片单的子地图。作品和片单按固定 ID 范围分片，并附页面更新时间。
- 图片：首屏的大图和 logo 立即加载（懒加载会让首屏变慢），其余全部 `loading="lazy"`；详情页的海报和剧照有描述文字（alt）。

## 添加到桌面

- 教程页：`/install`（不登录也能看），按设备显示 iPhone、安卓、电脑、微信内置浏览器的步骤；安卓 Chrome 和电脑上能一键安装。
- 应用清单 `/manifest.webmanifest`，图标在 `web/static/img`。
- Service Worker `/sw.js`：只缓存带版本号的静态文件、断网时显示离线页，不缓存页面和接口，也不经手任何跨域请求（播放源）。
- 前端模块通过 import map 带上版本号，可以长期缓存并并行预加载。
- 全屏打开时：顶部避开刘海和状态栏，二级页面显示返回按钮。
- iPhone 上桌面版和 Safari 不共享登录和本地数据：在桌面版里登录一次，播放源和观看记录会自动同步过来。

## 分享卡片

作品详情、短评、片单、月度报告都可以生成分享图片（1080×1440，带二维码），用于微信、朋友圈、小红书。图片由浏览器用 canvas 画（`web/static/js/core/sharecard.js`），服务器只在页面上提供文字和图片地址（`data-card`），不需要中文字体和图片处理。手机上可以直接分享图片（系统支持时）或长按保存，电脑上可以下载。主页没公开时，报告卡片上的二维码指向首页。
