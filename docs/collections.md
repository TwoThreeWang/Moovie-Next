# 片单与管理后台

## 片单

所有用户都可以做片单（`internal/collections`）。入口在顶部菜单的「片单」（片单广场 `/list`）和「我的 → 我的片单」（`/me/collections`，收藏的片单在 `/me/collections/favorites`）。

### 编辑

- 编辑器在 `/me/collections/new` 和 `/me/collections/:id`：搜索作品库里的片名加入，拖动或用按钮调整顺序，每部可以写一句推荐语。
- 限制：标题 80 字，简介 1000 字，推荐语 300 字，最多 200 部。
- 编辑内容随时存在本机（`localStorage`），意外关掉页面不会丢；片单在别处被更新过时，旧草稿不会自动覆盖，要用户确认后才恢复。
- 保存用乐观锁：表单带着打开时的 `updated_at`，期间被改过就提示冲突，不会覆盖。
- 可以在新标签页预览，不保存。

### 状态

| 状态 | 谁能看到 | 说明 |
| --- | --- | --- |
| 草稿 `draft` | 只有自己 | 可以开启「链接访问」，拿到链接的人能看，但不进广场、主页和站点地图 |
| 待审核 `pending` | 只有自己和管理员 | 投稿后等管理员审核；期间还能修改，管理员审核的是最新内容 |
| 已发布 `published` | 所有人 | 显示在片单广场和作者主页，进站点地图 |
| 被退回 `returned` | 只有自己 | 附审核意见，改好可以再投；同样可以开启链接访问 |

### 修改已发布的片单

已发布的片单改了以后要重新审核，但公开页不能因此消失：

- 修改稿存在 `collections.revision`（jsonb），公开页照常显示正式内容。
- 审核通过：把修改稿合并进正式内容并清空，收藏和浏览数保留。
- 退回：保留修改稿和原因，作者可以继续改，也可以「放弃修改」。
- 作者撤回或管理员下架时，修改稿同样先合并，避免作者的修改丢失。
- 作者在「我的片单」和编辑器里看到的是修改稿，访客和搜索引擎看到的始终是正式内容。

### 收藏、浏览和热门

- 登录用户可以收藏已发布的片单。取消收藏只标记为不活跃，再次收藏时重新计时。
- 浏览按"片单 + 日期 + 访客"去重，同一个人一天只算一次；去重记录只保留最近 7 天。
- 片单广场有「最新发布」和「近 7 天热门」两种排序：热门按最近 7 天新增的收藏人数排，人数相同时比较去重浏览量。热门排序页不让搜索引擎收录。

### 通知

片单审核通过、被退回、被下架时，作者会收到站内通知（附原因）。

## 管理后台

`/admin`，只有管理员能进（第一个注册的账号是管理员）。入口在「我的」页面里的「管理后台」，顶部菜单不显示。

| 页面 | 做什么 |
| --- | --- |
| 概览 | 各项数字（含待审核片单、待处理反馈、短剧总数、资料完整的、待抓的）；外部服务（豆瓣和红果的请求节奏、TMDB、AI、向量、发信、Telegram 图床）是否正常；还有多少作品和短剧在等采集；手动刷新热门榜、短剧榜单和重点剧目、收录新上架的短剧；最近 30 天每天的新用户、观影人数、新标记、回复、弹幕、搜索、发信 |
| 用户 | 搜索、设管理员、生成重置密码链接、删除；**禁言**（不能发短评、回复、弹幕，其他照常，会收到通知）和**封禁**（不能登录，立即踢下线），可以选 1 / 7 / 30 天或永久，要写原因。管理员不能被限制 |
| 作品 | 按"电影、剧集、综艺、动漫"和"短剧"分开看（短剧会比其他作品多两个数量级）；搜索框可以填片名、豆瓣 ID，或者直接粘贴豆瓣、红果的链接；添加作品同样认豆瓣 ID / 链接和红果链接；同步、隐藏 |
| 片单 | 审核队列包括新投稿和已发布片单的修改（标"修改"），按提交时间排；可以通过、退回（写原因），已发布的可以下架 |
| 内容审核 | 最新的短评、回复、弹幕，可以按内容或用户名搜，批量删除；删短评和回复时作者会收到通知（附原因） |
| 反馈 | 用户反馈列表，回复后用户会收到通知 |
| 屏蔽词 | 片名命中的作品自动隐藏，命中的搜索词不上热搜榜 |
| 任务 | 后台任务队列：排队、运行中、失败的任务和失败原因，可以重试失败的任务 |
| 广告指纹 | 只读：每个指纹的确认票、否认票、状态、最早出现和最近投票时间，用来发现异常。不提供人工裁定——管理员看不到画面，没有依据判断；是不是广告由看到画面的人投票 |
