# 播放源与播放器

本站不提供、推荐或保存任何播放源。用户在「设置 → 播放源」里填写自己的订阅地址，查询和播放都在浏览器里完成。

## 订阅文件

订阅地址指向一个 JSON 文件，列出用户自己的资源站（苹果 CMS 接口，JSON 和 XML 都支持）：

```json
{
  "version": 1,
  "sources": [
    { "key": "a", "name": "我的源 A", "api": "https://example.com/api.php/provide/vod/" }
  ]
}
```

- 每个源需要一个不变的 `key`；没有或不合规时按接口地址生成一个稳定的。一份订阅最多 60 个源。
- 订阅 6 小时没更新会重新读取，读取失败时继续用旧的。
- 解析代码在 `web/static/js/lib/cms.js`，只解析、不发请求，方便测试。

### 兼容 TVBox 配置

订阅地址也可以直接填 TVBox 配置（`web/static/js/lib/tvbox.js`）：

- 只导入 `sites` 里 `type` 为 0（XML）和 1（JSON）、可以搜索的站点，它们就是苹果 CMS 接口。能识别注释、多余的逗号、BOM 和相对路径，同一个接口只留一个。
- 不使用：`type` 为 3 等爬虫站点（要运行 jar / js / py 爬虫，等于在本站执行第三方代码）、`parses`（多用于解析正版平台的 VIP 链接）、`lives`、`spider`。跳过的数量显示在源列表下面。
- 加密、编码或藏在图片里的配置，以及多仓配置（`urls` / `storeHouse`）暂不支持，会给出明确提示。
- 想删除这个功能时，按 `tvbox.js` 开头的清单删除即可，不涉及数据库和同步格式。

## 查询的转发

大多数资源站没有给网页跨域许可，浏览器直接查询会被拦下；HTTP 接口在 HTTPS 页面里也访问不了。这类查询由服务器转发：`GET /api/relay?url=…`（`internal/relay`）。

- **只转发订阅文件和查询**（苹果 CMS 的 `ac=detail`，一次请求就带回搜索结果、详情和播放地址），一律走转发，不先试直连。本站自己的地址和本机地址（开发用的模拟源）由浏览器直接访问。
- **视频不转发**：m3u8 和分片仍由浏览器直接加载；视频服务器不允许跨域的线路，hls.js 播不了，会立即换下一个（Safari 用系统播放器，不受影响）。
- **防滥用**：要登录；每个账号每分钟 300 次；同时最多转发 64 个请求；单次最多 2 MB、8 秒；只转文本，视频、播放清单、图片一律拒绝；内容一律当纯文本交回（`text/plain` + `sandbox`），不会以本站身份被当成网页打开；不记录转发的地址。
- **防内网探测**：检查放在建立连接时，本机、内网、链路本地等地址一律拒绝，域名解析到内网或者跳转到内网都会被拦下。代理软件 fake-ip 用的 198.18.0.0/15 放行（这类网络环境里所有域名都解析到这个网段）。

## 在线 M3U8 播放器

`/m3u8`，不用登录。粘贴 m3u8、HLS 或 MP4 链接直接在同一页播放。这是一个常被搜索的工具，所以按落地页来做 SEO：独立的标题和描述、使用说明、常见问题（页面上的问答和 `FAQPage` 结构化数据是同一份）、`WebApplication` 结构化数据、站点地图、页脚链接。

- 链接放在网址的 `#` 后面，服务器收不到；视频由浏览器直接加载。复制分享链接也是这个格式。
- 粘贴一个完整的链接就自动开始播放；也可以把链接拖到播放器上。
- 最近播放的 10 个链接和各自的进度只存在本机（`localStorage`），再次打开从上次的位置继续；能播起来的链接才会记下。
- 播放清单返回 4xx 时立即提示"链接过期或对方不允许"，不等超时；HTTP 链接会先换成 HTTPS 试一次，不行就说明原因。
- 和作品播放共用同一个播放器：自适应缓冲、慢线路提示、倍速、画中画、手势、快捷键、广告跳过。游客也能跳过大家确认过的广告（指纹列表公开），但投票要登录。

## 广告跳过

用 hls.js 播放时，分析的是 hls.js 实际加载的那一份播放清单（通过 `pLoader` 观察，不修改），分片路径按跳转之后的最终地址解析，切换清晰度时换成那一路的分析结果。Safari 用系统播放器时看不到它加载的清单，只能另外下载一份分析（同样按最终地址解析）。

指纹由服务器下发、在浏览器里本地比对，不上报用户在看什么；是不是广告由看到画面的人投票（疑似广告时的询问、自动跳过后"撤销 → 这段不是广告"）。

## 慢线路

- 缓冲往前多攒（最多 60～180 秒），分片下载超时放宽到 40 秒，慢但在下载的分片不会被反复中断。
- 边播边算当前线路的倍速（每秒能下载几秒视频）；连续 3 个分片低于 1.3 倍时，试探其他线路（下载清单和第一个分片的开头，最多 1.5 MB，一分钟最多一次），有明显更快的就提示，点"切换线路"才换。卡住超过 8 秒也只提示，不自动换。
- 往前缓冲多少按情况调整（只对 hls.js 有效，Safari 的系统播放器自己决定）：线路快（2 倍速以上）时 60 秒；线路勉强够用（不到 2 倍速）时边播边攒到 3 分钟，扛住更长的网速低谷；暂停时攒到 5 分钟。线路比视频码率还慢时缓冲多少都会被耗光，靠提示换线路。
